# Laboratorio 3 - Algoritmos de Enrutamiento

Implementación individual y modular de los algoritmos solicitados en CC3067 Redes:
Dijkstra, Flooding, Link State Routing (LSR) y Distance Vector Routing (DVR).

El proyecto usa Python 3.11 o superior y no requiere dependencias externas para
ejecutarse. La documentación de instalación, uso y arquitectura se completará junto
con la implementación.
